Bike Store - Sistema de Gestión de Clientes y Pedidos

Este proyecto es un sistema de gestión para una tienda de bicicletas, donde puedes gestionar productos, categorías, clientes y órdenes. Desarrollado con PHP y MySQL, el sistema permite a los administradores crear, listar, editar y eliminar clientes y pedidos, así como realizar filtrados en las vistas de lista.

Funcionalidades

Gestión de Clientes

Listar todos los clientes.

Crear un nuevo cliente.

Editar la información de un cliente.

Eliminar un cliente.

Filtrado de clientes por nombre, apellido, email y teléfono.

Gestión de Pedidos

Crear un nuevo pedido.

Listar todos los pedidos.

Eliminar y anular un pedido.

Filtrar pedidos por cliente, fecha y estado.

Interfaz de Usuario

Diseño limpio y atractivo con animaciones y transiciones al pasar el cursor.

Funcionalidad de búsqueda en las tablas para filtrar datos.


Requisitos

Para ejecutar este proyecto, asegúrate de tener las siguientes herramientas:

PHP (>= 7.4)

MySQL

Servidor Web (Apache o Nginx)
